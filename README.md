# NetScan GUI

Графическая программа для визуализации структуры IP-сети
и подключённых устройств. Windows 10, PySide6.

## Сборка

1. Установите Python 3.10+ с python.org (галочка "Add to PATH").
2. Двойной клик по `build.bat`.
3. Готовый файл: `dist\NetScanGUI.exe`.

## Использование

1. Запустите `NetScanGUI.exe` (двойной клик).
2. Подтвердите запрос UAC.
3. Введите подсеть (обычно подставляется автоматически).
4. Нажмите **"▶ Начать сканирование"**.
5. Устройства появятся в таблице слева и на графе справа.

## Управление графом

- **Ctrl + колесо** — зум
- **ЛКМ по узлу** — перетащить
- **ЛКМ по пустому месту** — панорамирование рамкой
- **Клик в таблице** — фокус на узле

## Экспорт

- **💾 PNG** — статичный снимок графа
- **📄 CSV** — таблица устройств (Excel-совместимо)

## Требования

- Windows 10/11
- Права администратора (для корректного ARP-опроса)
- Локальная сеть / VLAN

## Правовое предупреждение

Сканирование допустимо только в собственной инфраструктуре
или с письменного разрешения владельца.
